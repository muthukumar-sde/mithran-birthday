# Mithran's 1st Birthday Celebration ❤️✨

A beautiful, interactive, and personalized web application created with love by **Muthukumar & Pavithra** to celebrate the 1st Birthday of their darling son, **Mithran**.

---

## ✨ Features

- 🌟 **Dynamic Hero Section**: 
  - Letter-by-letter animated title reveal powered by Framer Motion.
  - Floating dancing photo frames highlighting special baby avatars (Little Krishna, Lord Murugan, Cutie Avatar, Kadhukuthu ceremony, etc.).
  - Interactive glowing **Scroll to Explore** pill button with smooth scrolling.

- ⏳ **Interactive Milestone Timeline**:
  - Month-by-month journey from Month 2 coos up to the 1st Birthday celebration.
  - Rich imagery, icons, and animated milestone cards.

- 📸 **Precious Moments Photo Gallery**:
  - Custom grid layout featuring polaroids, hero cards, and tall photo frames.
  - Full-screen interactive lightbox viewer with smooth navigation controls.

- 💖 **The Story of a Name**:
  - Interactive equation card showing how the name **MITHRAN** was created with love by joining **Muthukumar** & **Pavithra**.

- 💌 **From Mom & Dad**:
  - Heartfelt birthday message card from parents with dedicated portrait imagery and signature.

- 🎂 **Virtual Cake Cutting & Celebration**:
  - Interactive candle blow-out feature with screen flash effects.
  - Custom canvas confetti explosion and particle fireworks.

- 🎵 **Background Music Player**:
  - Floating music widget with audio visualizer bars, volume indicators, and tap-to-play browser interaction prompts.

- 🔒 **Image Protection & Custom Cursor**:
  - Custom glowing cursor trailing effect.
  - Right-click and image-drag protection for baby photographs.

- 🎂 **Custom Birthday Cake Favicon**:
  - Vector SVG birthday cake favicon for crisp browser tab presentation.

## 🛠️ Technology Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **UI & Logic**: [React 19](https://react.dev/)
- **Styling**: Vanilla SCSS Modules (`.module.scss`)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: `canvas-confetti`

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18.0.0 or higher) and `npm` installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/muthukumar-sde/mithran-birthday.git
   cd mithran-birthday
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

To test or generate a production build:
```bash
npm run build
npm run start
```
